# 内容理解：从词语到可画的关系

## 先做事实账本

保留用户原文。给证据编号，逐条记录短引文、解读和依据类型：

- `explicit`：文字明示，可作为硬语义约束，如“孤舟”“晚回舟”。
- `inferred`：有依据但非唯一的解读，如孤独、洒脱；标注解释和不确定性，避免附会心理故事。
- `artistic`：为呈现意境设计的象征性材料或装置，如宣纸河面；不能冒充原文事实。

只给诗名时核实正文和版本。典故影响主题时从可信来源核实；无需为常见诗逐次搜一篇泛解读。用户原创以其文字为依据，不套入古典出处。无法核实典故时保留表层语义，避免画出猜测的历史事件。

## 七层理解与视觉接口

| 层 | 要问的问题 | 给图像模型的结果 |
| --- | --- | --- |
| 对象与谓词 | 谁做什么？否定什么？是一个还是多个？运动朝向如何？ | 明确的主宾、动作、数量、朝向；应出现和不应出现的对象 |
| 时空与进程 | 是何时何地？事件如何推进？几种时间是否共存？ | 时辰一致的光线；一个关键瞬间或主场景加克制的时间痕迹 |
| 观察者 | 谁在观察？身在景内还是望向远方？画中人物是否有依据？ | 镜头位置、可见范围、前景遮挡；不自动画诗人肖像 |
| 情绪与转折 | 起点与终点情绪是什么？哪一个字使情绪改变？ | 空间压迫或舒展、重心、密度、光的开放程度；不是抽象形容词 |
| 感官与节奏 | 哪些声、色、触感或重复制造节奏？ | 动势、涟漪、连续形态、疏密与停顿；不必加发声者或拟声文字 |
| 对照与修辞 | 诗靠何种差异成立？哪里是夸张、比喻或典故？ | 大小、远近、有无、虚实的构图机制；保留对照双方 |
| 主题与留白 | 去掉什么会让诗认不出来？哪些内容故意未说？ | 2–4 个语义锚点、一个主关系、有限想象范围与禁止项 |

不要给各层平均篇幅；只展开真正影响该诗视觉决策的层。简短原创诗也可只保留关键两三层。

## 从意义到画面，逐步编译

1. 写一句最小完整诗意，包含主体、关系与情绪。例如“万物踪迹消失的寒江上，一位老翁仍独自垂钓”。
2. 提炼必保留锚点，把动作关系列为一项，而非只列“雪、舟、老人”。
3. 选择主导构图机制，如“极小的一舟一翁，对照巨大无人的雪江”。
4. 将感官与情绪落到能观察的形式上，如“无鸟无人、岸线稀少、细微水纹”，而非仅写“孤独感”。
5. 每条新增细节关联证据或说明它是艺术补充。无法解释其作用的道具删掉。
6. 明确构图变量与语义不变量；先验证候选都符合诗意，再比较新颖度。不能通过增加原文禁止的鸟群让《江雪》更“丰富”。

## 例一：《江雪》的核心不是雪景贴纸

原文：千山鸟飞绝，万径人踪灭。孤舟蓑笠翁，独钓寒江雪。

| 证据 | 解读 | 可画指令 |
| --- | --- | --- |
| “鸟飞绝”“人踪灭” | 大范围的缺席；明示无鸟与无人的踪迹 | 山与路径疏而空，不画鸟、游客或脚印 |
| “孤舟”“独钓” | 单一舟翁与巨大环境的对照；钓鱼动作不能消失 | 仅一舟一翁，渔线／钓竿能辨认，主体占比小 |
| “蓑笠翁”“寒江雪” | 人物身份与寒江雪景明示 | 老翁穿蓑戴笠，冷白江面与雪；不能用米白女子替换其角色 |

“坚守、清孤”是可用但非唯一的主题解读，不能添加哭泣或绝望表情作为事实。日／夜未明示，不必捏造满月。宣纸可以成为艺术材质，但不能删掉独钓关系只剩空卷。

## 例二：《如梦令》的转折比荷花更重要

节选：兴尽晚回舟，误入藕花深处。争渡，争渡，惊起一滩鸥鹭。

将“晚归 → 误入 → 争渡 → 惊起”理解为时序，选“船从荷丛中穿出、鸥鹭骤起”作为最小完整高潮。晚光、荷丛、舟的方向与鸟的升起形成相互作用。“争渡”的重复可译成两组急促水纹或连贯桨迹，不用复制两条船，也不一定将所有时刻拼成连环画。

不要因为作者是女性就自动给出其历史肖像或多人游宴；若人物不是关键，允许小比例、不强调身份的舟中身影。

## 例三：宏观空间可以凝练，不应误读

“千里江陵一日还”“轻舟已过万重山”写速度与畅快；不要求画千里地图和一万座山。用连续岸影、舟的斜向穿行和前后景压缩呈现速度，同时以晨光和彩云保留时辰。猿声可由两岸空间呼应承载；如画猿，必须是克制的岸边细节，不能变成动物主角。

## 歧义与想象的限制

原文含多义或未明确时，选择证据支持、增加假设最少的视觉解释；其他解释只在用户要方案比较时展开。保留不明确的面容和身份，不给观者塞入虚构情节。允许补充天气纹理、合理服饰与材质细节，前提是它们不覆盖明示事实，也不新增决定性的事件。
