# 内容理解：从词语到可画的关系

## 先做事实账本

保留用户原文。给证据编号，逐条记录短引文、解读和依据类型：

- `explicit`：文字明示，可作为硬语义约束，如“孤舟”“晚回舟”。
- `inferred`：有依据但非唯一的解读，如孤独、洒脱；标注解释和不确定性，避免附会心理故事。
- `artistic`：为呈现意境设计的象征性材料或装置，如宣纸河面；不能冒充原文事实。

只给诗名时核实正文和版本。典故影响主题时从可信来源核实；无需为常见诗逐次搜一篇泛解读。用户原创以其文字为依据，不套入古典出处。无法核实典故时保留表层语义，避免画出猜测的历史事件。

## 八层理解与视觉接口

| 层 | 要问的问题 | 给图像模型的结果 |
| --- | --- | --- |
| 对象与谓词 | 谁做什么？否定什么？是一个还是多个？运动朝向如何？ | 明确的主宾、动作、数量、朝向；应出现和不应出现的对象 |
| 时空与进程 | 是何时何地？事件如何推进？几种时间是否共存？ | 时辰一致的光线；一个关键瞬间或主场景加克制的时间痕迹 |
| 观察者 | 谁在观察？身在景内还是望向远方？画中人物是否有依据？ | 镜头位置、可见范围、前景遮挡；不自动画诗人肖像 |
| 情绪与转折 | 起点与终点情绪是什么？哪一个字使情绪改变？ | 空间压迫或舒展、重心、密度、光的开放程度；不是抽象形容词 |
| 感官与节奏 | 哪些声、色、触感或重复制造节奏？ | 动势、涟漪、连续形态、疏密与停顿；不必加发声者或拟声文字 |
| 对照与修辞 | 诗靠何种差异成立？哪里是夸张、比喻或典故？ | 大小、远近、有无、虚实的构图机制；保留对照双方 |
| 意境基调 | 诗人是在记录眼前、夸张奇想，还是超然观照？情感是含蓄还是奔放？ | 写实程度、想象幅度、光色与形态的力度；见下文「意境基调」 |
| 主题与留白 | 去掉什么会让诗认不出来？哪些内容故意未说？ | 2–4 个语义锚点、一个主关系、有限想象范围与禁止项 |

不要给各层平均篇幅；只展开真正影响该诗视觉决策的层。简短原创诗也可只保留关键两三层。

## 从意义到画面，逐步编译

1. 写一句最小完整诗意，包含主体、关系与情绪。例如“万物踪迹消失的寒江上，一位老翁仍独自垂钓”。
2. 提炼必保留锚点，把动作关系列为一项，而非只列“雪、舟、老人”。
3. 选择主导构图机制，如“极小的一舟一翁，对照巨大无人的雪江”。
4. 将感官与情绪落到能观察的形式上，如“无鸟无人、岸线稀少、细微水纹”，而非仅写“孤独感”。
5. 每条新增细节关联证据或说明它是艺术补充。无法解释其作用的道具删掉。
6. 明确构图变量与语义不变量；先验证候选都符合诗意，再比较新颖度。不能通过增加原文禁止的鸟群让《江雪》更“丰富”。

## 意象分层：哪些能直画，哪些要转译

不要依赖图像模型自动区分字面与修辞。逐个意象归类后再写具体指令：

| 类型 | 判断 | 处理 | 例 |
| --- | --- | --- | --- |
| 实象 | 诗人眼前真实存在 | 可直接画 | 孤帆、长江、松间明月 |
| 喻象 | 比喻的喻体、拟物 | 画本体，让本体呈现喻体的质感，不画喻体本身 | “疑是地上霜”→ 地面月光清冷如霜，不画真霜 |
| 夸张 | 数量、尺度的修辞放大 | 转成尺度感、流动感或速度，不按数字画 | “白发三千丈”不画三千丈头发 |
| 虚象 | 想象、回忆、梦境、他处之人 | 可画，但用区别于现实的手法：倒影、半透明、窗中景、画中画 | “遥知兄弟登高处”的兄弟是想象 |
| 通感 | 声、香、温度、触感 | 优先转为形态节奏、距离与材料感；新增具体物件须另有依据 | 钟声可用空间回响感，不自动加塔；“寒”可用冷光与触感，不自动加霜 |
| 典故 | 承载典故的物 | 受众读不懂就转成情绪或关系，不直画典故物 | “青鸟”不是一只青色的鸟 |

先查古今异义与专名：“落木”是落叶，不是倒下的树；“沉舟侧畔”是自喻，不是实景沉船。名词错了，图像模型一定会忠实画错。

## 情景关系决定人物与色调

| 关系 | 画面倾向 |
| --- | --- |
| 借景抒情 | 景为主体，人物小或缺席 |
| 以乐景写哀 / 以哀景写乐 | 保留反衬：景越明丽越显孤独，不把乐景画成阴郁 |
| 有我之境 | 人物或人物痕迹在场（背影、空舟、斜放的伞），色彩带主观倾向 |
| 无我之境 | 可无人物，构图平静、对称或极简 |
| 托物言志 | 物为唯一主角，郑重、居中或巨大化 |

言外之意常是封面感的来源。“人面不知何处去，桃花依旧笑春风”说的是“人已不在”，画面要留一个“空”——盛开的桃花与空着的门或位置，而不是补画一位女子。

## 意境基调：诗人用什么方式看世界

情绪回答“感受到什么”，基调回答“用什么方式说出这种感受”。同是愁，可以白描如实，可以奇想夸张，也可以冷寂空灵；它决定画面应当可信具体，还是可以超越现实。基调由 Agent 根据本篇证据自行判断，不预设类别清单。

从几条可观察的维度入手，再综合成一句概括：

| 维度 | 要问的问题 | 原文中的线索 |
| --- | --- | --- |
| 写实 ↔ 想象 | 写的是眼前所见，还是夸张、比喻、幻想、梦游？ | 夸张数字、“疑是”“似”“如”、神话与天象、超常尺度；或具体地名、季节、物候、日常动作 |
| 情感力度 | 含蓄内敛还是奔放外露？沉郁下坠还是飞扬上扬？ | 感叹与反问、动词力度、句式长短、是否直抒胸臆 |
| 观照距离 | 身在其中的亲历、冷静旁观，还是超然物外？ | 是否有“我”、感官是否贴身、叙述是否节制 |
| 境界质感 | 整体气象像什么？ | 空灵、雄浑、奇诡、清丽、质朴、苍凉、谐趣、肃穆……只是举例，可自拟更准确的词 |

再写一句 `register`，并把它落实为画面上的决定：

- 想象幅度大：画面可以超出现实而成奇观——放大尺度、强化光与动势、允许非自然的色彩或空间，但仍画本体，让本体获得喻体的气质。
- 纪实感强：画面要具体、可信、克制——自然光线、真实材质与痕迹、平视或亲历视角，少用装饰与炫技效果；沉痛靠细节和空缺说话，不靠渲染。
- 空灵、超然：减少形态和事件，以空、静、虚处与微光承载。
- 奇诡、幽冥：可用不安的色彩、扭曲的尺度或冷硬对比，但要有原文中的奇崛意象作依据。
- 谐趣、童真：轻快的动势、明亮的色彩和略带夸张的形态，不画成庄严肃穆。

判断时注意：

- **只看本篇，不贴作者标签。** 李白也写白描的《静夜思》，杜甫也写“荡胸生层云”的《望岳》；流派印象只能作为线索，必须由本篇字句确认。
- **基调可以混合或转折。** 写实底色中可能有一处移情或奇想，豪放开篇可能转入苍凉。记录主基调与局部例外，让画面主调服从主基调，例外只作克制的点染。
- **基调不推翻意象分层。** 浪漫奇想仍不能把喻体画成实物；写实也不等于照片质感，更不等于补画原文没有的事件、人群或血腥场面。
- **基调与风格不是一一对应。** 浪漫可以是绘画、拼贴或强光摄影，写实可以是摄影、素描或沉着的水墨；基调决定写实程度与力度，媒介在视觉模块再选。

### 对照：《望庐山瀑布》与《春望》

“飞流直下三千尺，疑是银河落九天”：“三千尺”是夸张，“疑是银河”是比喻，诗人在惊叹中把瀑布想象成天上银河倾落。基调是**浪漫奇想的壮丽奇观**——想象幅度大、情感飞扬、仰望而惊叹。画面应超越写实：极端的垂直尺度、自天而降的光流、水雾中带星河般的闪烁与天光，让观者感到“这不只是一道瀑布”。仍画瀑布本体，不在瀑布旁另画一条银河，也不按三千尺去测量；若画成一张平实的风景照片，就丢掉了这首诗。

“国破山河在，城春草木深”：“国破”与“山河在”、“城春”与“草木深”并置，用具体可见之物写出亡国的荒凉——城中春草疯长，是因为人迹已稀。基调是**沉郁克制的纪实**——写实程度高、情感内敛而深重、诗人身在其中亲历。画面应可信、具体：残破城垣、无人打理而过深的草木、春天的自然光，明丽春色与人事荒败形成反衬。不要梦幻柔光、仙气云雾或唯美滤镜，也不补画战争场面；“感时花溅泪，恨别鸟惊心”是移情，可作为极克制的细节（如沾露的花），不能画成会哭的花。

## 完整示例：从证据到可画指令

以下示例只演示方法，不是本 skill 偏好的题材或画法。

原文：千山鸟飞绝，万径人踪灭。孤舟蓑笠翁，独钓寒江雪。

| 证据 | 解读 | 可画指令 |
| --- | --- | --- |
| “鸟飞绝”“人踪灭” | 大范围的缺席；明示无鸟与无人的踪迹 | 山与路径疏而空，不画鸟、游客或脚印 |
| “孤舟”“独钓” | 单一舟翁与巨大环境的对照；钓鱼动作不能消失 | 仅一舟一翁，渔线／钓竿能辨认，主体占比小 |
| “蓑笠翁”“寒江雪” | 人物身份与寒江雪景明示 | 老翁穿蓑戴笠，冷白江面与雪；不能用无依据的其他人物替换其角色 |

“坚守、清孤”是可用但非唯一的主题解读，不能添加哭泣或绝望表情作为事实。日／夜未明示，不必捏造满月。艺术装置可以作为材质隐喻，但不能删掉独钓关系只剩装置。

## 两类常见难点

**叙事有时序时，选最小完整高潮。** 把原文事件排成时序，选能同时呈现因与果的一个瞬间，而不是把所有时刻拼成连环画；重复句式转为节奏（连续水纹、重复笔触），不复制主体。人物不是关键时，允许小比例、不强调身份的身影，不因作者身份自动画作者肖像。例：《如梦令》“误入→争渡→惊起”取“舟从荷丛穿出、鸥鹭骤起”。

**宏观尺度要凝练，不要计数。** 千里、万重等写速度、距离或气势，用连续形态、斜向运动、前后景压缩表现，同时保留原文时辰；声音由空间呼应承载，发声物如要出现只作克制细节。例：《早发白帝城》不画千里地图和一万座山。

## 歧义与想象的限制

原文含多义或未明确时，选择证据支持、增加假设最少的视觉解释；其他解释只在用户要方案比较时展开。保留不明确的面容和身份，不给观者塞入虚构情节。允许补充天气纹理、合理服饰与材质细节，前提是它们不覆盖明示事实，也不新增决定性的事件。

## 交付前误读核对

- 喻体、夸张被当成实景或实数。
- 服饰、建筑与已知文化身份或时代错置；形式语言的借鉴不能把原文角色变成另一地域或时代的人物。
- 季节、时辰与原文矛盾（秋诗盛开荷花、“春寒”却衣着单薄、夜诗画成白昼）。
- 反衬写成同调；边塞豪放被画成柔美小景，婉约小令被画成宏大全景。
- 基调错位：奇想夸张的诗被画成平实风景照，纪实沉痛的诗被画成梦幻唯美；或仅凭作者名声判定基调。
- 典故直画导致看不懂。
- 为“像古风”堆灯笼、油纸伞、竹林、仙鹤、月亮等与原文无关的通用素材。

把以上理解交给视觉模块时，明确意境基调、主导空间方向、明暗反差、情景反衬与文字长度，作为风格和画幅的选择依据。不要在内容理解阶段预设白底、纸纹、宋体或竖版；诗意锚点固定，表现形式可变化。
