# 从原文推导风格、比例与尺寸

## 先确定要被看见的关系

写出一句画面任务：主体如何存在、移动、相隔或显露，以及最重要的感官反差。由此决定形式，而不是从“古诗→水墨”“愁→灰色”“豪迈→横幅”直接跳结论。

| 原文信号 | 可能有帮助的表现机制 | 需要比较的选择 |
| --- | --- | --- |
| 稀疏、静默、微光、细节 | 克制摄影、细笔绘画、局部明暗、少量形态 | 特写或远景；方幅聚焦细节，竖幅组织纵深，横幅承载距离 |
| 江流、辽阔、连续山岸、去来 | 宽阔景深、连续形态、摄影或有方向的绘画笔触 | 横幅延展空间；竖幅也可表现水势落差，不能只凭“江”选宽幅 |
| 高山、瀑布、攀登、仰望 | 上下尺度差、垂直动线、厚重体积或结构线 | 竖幅候选；若人与山的横向对照更关键则改横幅 |
| 力量、冲突、悲壮、急促节奏 | 有力度的版画／绘画、硬边、撞击形态、局部强对比 | 宽幅、方幅或竖幅随冲突方向比较，避免一律柔光淡彩 |
| 花叶、近景触感、轻快转折 | 工笔、清透插画、摄影、轻笔触与突然展开 | 方幅或较宽竖幅容纳事件关系；狭长幅不能挤掉舟与鸟 |
| 梦、神游、奇崛尺度、虚实转换 | 有语义依据的超现实、拼贴、倒影、抽象空间 | 明确现实／虚象边界；不能凭风格增加新的决定性事件 |
| 乐景写哀、今昔不在 | 明丽景物与空缺位置、温暖细节与遥远距离 | 保留反衬，材质和明暗不替代核心关系 |

这些是候选生成提示，非固定映射。每首诗至少找到一条具体证据解释选中方案，并说明它比备选更适合的原因。

## 意境基调决定写实程度

在选媒介之前，先用内容理解得到的 `register` 定下两件事：画面离现实多远（写实程度与想象幅度），以及形态、光线、色彩用多大力度。不同基调的倾向举例如下，Agent 应按本篇自行判断，可混合，也可选择表外的表现：

| 基调举例 | 写实程度 | 形态、光线与色彩倾向 |
| --- | --- | --- |
| 浪漫奇想、夸张壮丽 | 低到中，可超现实 | 极端尺度、强光与动势、天象般的色彩；本体带上喻体气质 |
| 沉郁纪实、家国或民生 | 高 | 自然光、真实材质与残损痕迹、平视或亲历视角、克制饱和度，少装饰 |
| 空灵、超然 | 中，可虚化 | 稀少形态、大面积空与静、微光，细节点到即止 |
| 雄浑、苍凉 | 中到高 | 宽阔体量、粗粝质感、远距离与风沙光线 |
| 奇诡、幽冥 | 低 | 不安的色彩与对比、扭曲尺度，须有原文奇崛意象作依据 |
| 清丽、婉约 | 中 | 细腻笔触、柔和层次、近景与局部，不放大成宏大全景 |
| 谐趣、童真 | 中 | 轻快动势、明亮色彩、略夸张的形态 |

例如《望庐山瀑布》可比较超现实的竖幅天光瀑布、强光摄影式的仰拍奇观、青绿重彩的天河倾泻，排除平实的景区风景照；《春望》可比较纪实摄影式的荒城春草、沉着素描或水墨的断垣近景，排除仙气云雾与梦幻滤镜。最终在 `presentation.style_reason` 中写明基调如何影响了写实程度。

## 风格须成为一组具体决定

记录：媒介／笔触、写实程度、基底与主色、亮暗结构、纹理、形态密度、字体与文字区。不要只记录“国风”“高级”或艺术家名字。

- 要绘画就写清笔触、色层和边缘；要摄影就写清观看位置、景深与自然结构；要版画就写清线、块面与节奏。
- 水墨可以浓烈，摄影可以暗调，工笔可以饱和，宣纸也可以不出现。所选形式须保留关键关系和文字可读性。
- 故事发生的时代与文化身份属于语义约束；现代媒介或形式借鉴不等于允许服饰、建筑与原文角色错置。
- 调色盘可结合原文明示色彩与合理推演；“夜”通常影响光线，“愁”不必等于暗色。背景色与人物心理分开判断。
- 同系列优先保留一两个共同联系，不默认统一所有形式。用户明确要求统一尺寸时，各诗在那个画幅中重新组织，不能机械裁切。

## 比例选择

在内部比较主体展开方向、关键物象间距、阅读路径、文字长度与使用槽位。候选例包括 1:1、4:3、3:2、16:9 横幅，3:4、2:3、9:16 竖幅；并不限定为这些比例。极窄长卷、超宽景观仅在原文机制和工具能力同时支持时选择。

选择顺序：

1. 用户明确指定比例、像素或槽位时遵守。若三者互相矛盾，说明具体矛盾并请求取舍，不假装同时满足。
2. 用途明确但没有画幅时，根据真实槽位或出版要求选取；未知平台规格不得猜成硬约束。
3. 用途未明确时，让关键空间关系和文字阅读决定比例，自主选择一张，不为一般审美选择追问。
4. 工具仅支持有限画幅时，选最接近且保持语义的合法比例，先重构版面再出图。用户强制精确比例时不能悄悄替换。

例如同一“巨浪拍岸”可比较横向江岸展开与竖向浪峰撞击；优先选择把关系呈现得更清楚的方案，不能认定诗名决定唯一比例。

## 尺寸选择与实际核验

- 比例是构图选择，像素是细节与交付选择，分开推理。检查当前工具／模型支持的长短边、面积、步长和枚举；没有暴露尺寸参数时，只提出期望，不编造可控参数。
- 按实际用途与文字量选足够的清晰度。社交预览不自动追求最高像素；印刷只有已知物理尺寸、出血和输出要求时才计算需要的像素，不把“300 DPI”标签当成分辨率。
- 不为了增加像素数无必要地再生图，也不把放大后的图称为原生高分辨率。
- 若用户只指定像素，比例由宽高确定；只指定比例则选择工具支持的尺寸；均未指定则自适应。同时指定而相互矛盾时说明并请求取舍。
- 本地可读图像用真实宽高核验。自适应模式中不超过 1% 的比例相对舍入误差可接受，记录实际尺寸与实际比例。更大偏差会影响动作关系、版式或用途时重做，不能只改记录去迁就失败结果。
- 用户强制精确尺寸／比例时精确满足；无能力满足则说明限制。不能擅自拉伸人物、截掉诗句或删除语义锚点来凑比例。若需要后期编辑，遵循当前图像工具规范并重新验收。

## 历史变化的边界

将风格、比例、尺寸策略与实测尺寸放在 `presentation`，使后续比较能看到选择的依据。它们提供额外信息，不取代七个核心构图轴：单纯改变画幅、像素数、风格名称或背景色，仍是相似构图。

原文明示光线、主体关系与用户锁定的形式可以保持；去重应改变仍有自由度的观看位置、构图机制、尺度、文字区等，不能为凑三个维度而违背原文。
