# 行为验收案例

先预演语义规格与提示词；必要时再选少量真实出图。预演不调用生成、不登记成功作品，不将提示词检查视为图像验收。

| 原文／请求 | 必须保留 | 不应偏离 |
| --- | --- | --- |
| 柳宗元《江雪》：千山鸟飞绝，万径人踪灭。孤舟蓑笠翁，独钓寒江雪。 | 无鸟无人对照一舟一翁、独钓、寒江雪 | 群鸟游客、暖春、女子替代钓翁 |
| 李白《早发白帝城》：朝辞白帝彩云间，千里江陵一日还。两岸猿声啼不住，轻舟已过万重山。 | 晨光彩云、轻舟快行、两岸连续山势、畅快 | 黄昏静坐、雪景、强行卷轴替代舟山 |
| 李清照《如梦令》节选：兴尽晚回舟，误入藕花深处。争渡，争渡，惊起一滩鸥鹭。 | 晚归、误入荷丛、争渡惊起鸟群的因果 | 静态荷花装饰、独钓、取消鸟群、任意爱情情节 |
| 王维《山居秋暝》节选：明月松间照，清泉石上流。 | 松间月光与石上流水关系 | 白昼、雪景、凭空添加抚卷女子 |
| 李白《静夜思》：床前明月光，疑是地上霜。举头望明月，低头思故乡。 | 地面月光如霜的质感、举头与低头的转折、思乡 | 画真霜或雪、窗前书生套路图、暖黄灯火 |
| 崔护《题都城南庄》：去年今日此门中，人面桃花相映红。人面不知何处去，桃花依旧笑春风。 | 门、盛开桃花、“人不在”的空缺，今昔对照 | 补画女子当作现实在场、把明丽桃花画成阴郁 |
| 原创：我把未寄出的信，折成一只逆流的船。 | 未寄信、折纸船、逆流关系 | 编造古代作者、强加古装人物 |

补充行为场景：

1. 同诗再做：提供真实分类和历史图；至少三项未锁定维度变化、至少一项空间变化，语义关系保留。
2. 只改字：锁定垂卷、米白女子、抚卷与固定视角；应按编辑执行，不为创新改掉硬约束，不记为新原创。
3. 无原文：只给海报风格；应索取诗文，不自行挑诗。
4. 错字和署名：保留用户底稿并说明疑点，不静默纠错或补假作者。
5. 无工具／无 model 字段／强制不可用模型：不得声称生成或锁定模型成功。
6. 图像生成失败／文字错误：不写成功历史，定向修正；两次失败后按文字兜底规则处理。
7. 歧义：不给出原文不支持的叙事；把艺术隐喻标成隐喻，把主题推断标成推断。
8. 感官与修辞：“疑是地上霜”画本体月光而非霜；猿声不必变猿猴主角，“万重山”不需机械计数，“争渡”不复制船只。

真实出图验收必须观察画面锚点、动作、文字、作者、比例与历史差异；不能以提示词出现相关关键词作为通过理由。
