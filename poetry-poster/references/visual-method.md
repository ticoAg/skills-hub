# 视觉展示方法

## 依诗意选主机制

| 语义关系 | 可用构图 | 避免 |
| --- | --- | --- |
| 众景空寂与一人存在 | 极小主体、大留白、疏岸线 | 以悲哭表情替代空间关系 |
| 快行与归返 | 斜向穿行、连续岸影、透视压缩 | 一律静立凝望 |
| 隔望与回忆 | 窗缘／门槛、距离、虚实前后景 | 凭空编写爱情剧情 |
| 误入与惊起 | 遮挡后显露、骤起水纹、突变动势 | 满屏堆砌场景物，丢失动作 |
| 光源与流动 | 上方透光、下方流线、冷暖微差 | 为提高明度而改变时辰 |

选择一种主路线：凝练写景、局部感官、当代东方装置或虚实叠置。使用纸、帘、地台、卷轴等装置时明确其艺术隐喻身份；保留本诗的主体关系，不把装置当成通用主角。候选应有不同的视觉机制，而非同一模板填不同物件。

### 可选视觉路线

拟三种候选时，从不同路线中取，避免三张只是换物件：

| 路线 | 做法 | 适合 |
| --- | --- | --- |
| 诗眼特写 | 只放大一个物或动作（一枚落叶、手指触水） | 情绪集中于一个细节 |
| 超现实尺度 | 某意象巨大化或人物极小化（巨月、垂卷、悬空江水） | 浪漫、奇崛、壮阔 |
| 以物代人 | 只画人留下的物：空舟、半杯茶、未寄出的信 | 言外之意是“不在”“已去” |
| 留白隐喻 | 空白本身就是江、雪、天或愁 | 空寂、辽远 |
| 剪影叙事 | 逆光轮廓强调动作 | 送别、边塞、登高 |
| 虚实叠置 | 倒影、窗中景、半透明叠影并置现实与想象 | 有虚象、今昔对照 |
| 微观宇宙 | 把诗中世界缩进茶盏、砚台、掌心、一片叶 | 闲适、哲思小品 |

## 色彩与质感

依据原文与选定媒介选择明度、冷暖、饱和度和纹理，不固定宣纸白与高明度。清泉可用透明青，荷丛可用浅绿，晨光可用暖金，雪可用冷白；这些仅为候选。光线与时辰一致，反衬关系保留；不能为“禅意”强加灰滤镜，也不能因“愁”把明丽春景变成阴天。

朱砂、纸纹、做旧、浓墨与粗笔触均按所选风格决定，不是必需或一概禁止。若用装饰印记，保持少量且不含随机伪文字。媒介可有肌理，但不能遮住核心动作与文字。人物服饰与身份遵守原文，未知处克制处理。

## 用户锁定的装置与人物

用户锁定某种装置（如巨大垂卷、地台、帘幕）或人物（性别、服装、动作）时，它们是硬约束，不是本 skill 的默认风格。没有锁定时，人物性别、数量、动作与身份只来自原文；无依据时优先不画人物，或不强调身份。

同系列沿用锁定元素时，只在剩余自由维度上变化：视角、装置的空间层级、尺度、主体与装置的接触关系、文字区。自由维度不足时说明，不承诺大幅去重。

### 传统色参考

传统色适合时，从下表参考基底／主色／点睛。比例按视觉主次和媒介决定，不固定点睛面积；也允许采用其他色彩体系：

| 方案 | 基底 | 主色 | 点睛 | 倾向 |

| 宣纸朱砂 | 宣纸白 #F5F0E6 | 浅墨灰 #8A8A85 | 朱砂 #C0392B | 明、中性 |
| 月白黛蓝 | 月白 #D6E4EA | 黛蓝 #2E4A62 | 银白 #F2F2F2 | 冷、月夜 |
| 赭石藤黄 | 米白 #EDE4D3 | 赭石 #9C5B33 | 藤黄 #E3A82B | 暖、秋 |
| 青绿留白 | 绢白 #EFE9DC | 石青 #1F6E8C / 石绿 #3E8E6E | 金 #C9A44C | 明、山河 |
| 霁青胭脂 | 霁青 #D9E6EC | 雪白 #FAFAF7 | 胭脂 #9D2933 | 冷、清 |
| 秋香烟灰 | 烟灰 #C9C3B8 | 秋香 #B5A35A | 枫红 #B4442D | 暖、萧瑟 |

暗色与亮色都须服务原文的光线、空间或情景关系；可使用局部强对比，不限制为“夜色才能暗”。不要把整张诗词海报都套成高明度宣纸白。
