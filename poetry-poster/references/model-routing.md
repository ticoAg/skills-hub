# 图像工具与模型路由

1. 检查当前图像工具的真实参数；普通请求优先内置工具，有 imagegen skill 时先遵守它。
2. 将 `gpt-image-2.5` 视为家族偏好，除非用户明确强制精确版本。API／CLI 模式先核实官方模型标识、接口参数及账号权限。
3. 2026-10-13 检查的 [OpenAI 官方定价页](https://platform.openai.com/pricing) 列有 `gpt-image-2.5-sunburst` 与 `gpt-image-2.5-flare`。这不证明裸标识 `gpt-image-2.5` 有效，也不证明用户拥有调用权限；执行时重新核实，不凭快照猜参数。
4. 内置工具无 model 字段时，不增加该字段，不声称选定某个 API 版本。用户仅参考示例风格时使用可用工具；强制指定模型但工具不能满足时，说明限制并暂停出图，仍可先交付完整提示词。
5. 用户未请求 API／CLI 时，不增加 SDK、付费 API 测试或依赖安装。API 实现依照环境现有 CLI 与 [官方图像生成文档](https://platform.openai.com/docs/guides/image-generation)，不在本 skill 固定端点、尺寸与质量枚举。
6. 不静默降级；内置生成无需 API key，API 凭证使用环境或连接配置，不粘贴聊天、不写入仓库。
7. 完全无图像工具时交付可执行提示词，明确尚未出图，不记录成功历史。
8. 风格和目标比例由原文及用途推导；像素尺寸再根据当前工具能力选择，不把模型家族与固定画幅绑定。内置工具不暴露 size 时，不宣称精确像素可控；核验真实输出。比例或尺寸为用户硬要求而无法满足时说明，不静默改成另一画幅。
